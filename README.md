# Glass Home

An Android launcher styled like iOS 27: Liquid Glass dock, folders, menus and search, with a Clear ↔ Tinted glass slider.

**Install:** open the latest release on this repo → download the `.apk` → install → open **Home Settings** → *Set as Default Home App*.

Each push to `main` builds a new APK automatically (Actions tab → "Build APK") and publishes it as a release.

## What's in it
- **Home Screen**: pages of squircle icons (4×6, 5×6 or 4×5), labels, page dots that turn into the **Search** pill
- **Floating Liquid Glass dock** (up to 4 apps). The glass blurs and slightly magnifies the wallpaper behind it, with a darkened edge and specular rim (iOS 27)
- **Icon looks**: Default, Dark, Clear, Tinted (6 tint colours). Uses Android 13+ themed-icon glyphs when an app has them
- **Widgets**: analog Clock and Calendar month on page 1
- **Touch & hold an app**: glass quick-action menu with the app's own shortcuts, Edit Home Screen, App Info, Remove App
- **Jiggle mode**: hold an empty spot (or drag out of a menu). Drag to rearrange, drag to the screen edge to change pages, drop onto another app to make a **folder**, tap the minus badge to remove, tap the folder name to rename
- **App Library**: swipe past the last page. Auto categories plus Suggestions and Recently Added; tap the search field for an A–Z list
- **Spotlight**: swipe down anywhere. Top Hit, apps, calculator, web and Play Store search
- **Wallpapers**: 4 built-in ones generated on the phone (they dim in Dark mode), your own photo, or the system wallpaper. There's also a button to use it on the lock screen

No INTERNET permission. Apple's icons, wallpapers and fonts aren't included. The design copies iOS; the artwork is original.
